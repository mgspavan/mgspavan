## 🏆 Highlights

| Area | What I built |
|---|---|
| **AI copilot & generative UI** | Typed SSE streaming protocol that turns LLM output into option pickers and segment/report previews, with user confirmation before any create action and sanitized output to prevent XSS |
| **AI across workflows** | Audience, template, send-time and A/B suggestions; plain-language reports; cohort summaries; dashboard widget suggestions, with caching and per-session call limits to control latency and cost |
| **Self-service BI** | No-code report builder with query guardrails and drag-and-drop dashboards on Cube + ClickHouse |
| **Cohort analytics** | Funnel, Retention and Customer Journey (Sankey) views; any cohort becomes a segment or campaign in one step |
| **Engagement engines** | Visual Automated Journeys builder (10+ triggers, multi-channel actions, test mode) and audience segmentation (nested AND/OR, 15+ rule types, live counts) |
| **Performance** | Request deduplication, stale-response discarding and keyed caches; replaced 5-minute polling with Web Push; cut journey-load template requests from one per node to one per channel |
| **Platform upgrades** | Leading the move to Vue 3.5, Vuetify 3.13, Vite 8, Node 22, TypeScript 5.9 and Pinia 3, including CI/CD and Docker |
| **E-commerce** | Outfit customization module with 50+ options; Elasticsearch-backed search serving 2,000+ results per second |
